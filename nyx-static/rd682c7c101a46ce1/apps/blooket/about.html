Connect a Blooket tab

Save the Connect to Nyx bookmark from the app. Open the official Blooket website and click that bookmark. It opens Nyx in a second tab. Click the bookmark again after Blooket reloads.

The connector sends tool commands between those two tabs. It does not send your password, cookies or login tokens to Nyx. Connected means the tabs can communicate; it does not verify your account or sign-in.

Available tools

The library currently includes 27 reworked tools: Monster Brawl, Tower Defense 2, four Cyber Hack tools, Fishing Frenzy distraction removal, and seven question tools. Other entries are hidden. These implementations pass automated tests against supplied game code or controlled game fixtures; that is not a guarantee for every live Blooket update. Open the matching mode and screen before running a tool.

Stop scheduled tools cancels timers started by the connector. Disconnect also closes the connection. Neither reverses completed changes or signs you out of Blooket. Requests already sent may still finish. Favorites stay in this browser.
