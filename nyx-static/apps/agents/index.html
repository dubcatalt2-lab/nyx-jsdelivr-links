Add Nook to your app
  1. Create a key in Keys, then copy it. For an older key, choose Use Nook models and allowance.
  2. Store it on your server as NOOK_API_KEY. Keep it out of public browser code and repositories.
  3. Send a POST request to  with Authorization: Bearer YOUR_KEY and a model ID from the playground.
  4. Test it in Playground. Check Usage limits for remaining tokens and reset times.

Code on your computer
  1. Download the Windows companion and extract the ZIP.
  2. Open Start-N7X-Agents.cmd, or run node start.mjs from the extracted folder. Choose your project folder.
  3. Sign in to Nook, choose Code, then Connect folder. Allow local-network access and confirm the desktop prompt.
  4. Ask it to read, explain, review, or edit your project. Review the proposed changes and approve edits or commands on your desktop. Keep the companion running.
Use Nook as an app
In Chrome, open the browser menu, then Cast, save, and share → Install page as app. In Edge, open the browser menu, then More tools → Apps → Install this site as an app. This opens Nook in its own window; code tools still require the companion.
